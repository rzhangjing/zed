## provider 分层与 agent 链路小结

1. provider 是三层：`language_model_core`（纯协议/领域数据类型，无 UI 无注册表，chat_completion.rs 是共享的 OpenAI 消息结构）→ `language_model`（`LanguageModel`/`LanguageModelProvider` trait + `LanguageModelRegistry` + api key 抽象，面向 GPUI，RevN=11 的枢纽）→ `language_models`（唯一真正的 provider 实现集合与设置，`init()` 注册 5 个内置 provider + openai_compatible 动态注册）。
2. 协议层 5 个 crate 形态各异：`deepseek` = 官方 HTTPS API 且自带一套 wire 类型（**不依赖 language_model_core**）；`ollama`（:11434，本家 API + show/get_models 能力查询）、`lmstudio`（:1234/api/v0）、`llama_cpp`（:8080，router + 加载事件流）都是本机进程 HTTP；`open_ai` 是 OpenAI 线协议（含 Responses API 与 compaction），并被 openai_compatible 复用于任意兼容端点。
3. agent 是双轨：内置 `agent`（thread.rs 的 `AgentTool`/`AnyAgentTool` + ~30 个工具 + 沙箱/权限，并以 native_agent_server.rs 实现 `AgentServer` 对外提供 ACP）与外部 `agent_servers`（stdio JSON-RPC spawn gemini/claude-acp/codex-acp/cursor 等 CLI），两者都落到同一个 `acp_thread` 线程模型上。
4. `acp_thread` 是共享会话模型（条目/工具调用/权限/计划/elicitation/压缩/终端+diff）；`acp_tools` 只是 ACP 日志调试面板（唯一消费者 zed）；`agent_ui` 是统一呈现层（面板、消息编辑、模型/模式/档案选择、线程归档与 diff）。
5. 周边支撑：`agent_settings`（profile/AGENTS.md/自动压缩/sandbox+工具权限，RevN=9）、`agent_skills`（SKILL.md 加载，lib 在 crate 根）、`prompt_store`（heed/LMDB 提示词库，且依赖 agent_skills，负责 .rules→skills/AGENTS.md 迁移）。
6. `context_server` 是 MCP 客户端（stdio+HTTP、OAuth2 PKCE、`MCP-Protocol-Version` 协商），其 listener 还让 Zed 自身充当 MCP server；agent 中经 `ContextServerTool`（tools/context_server_registry.rs:304）接入。
7. `json_schema_store`（zed://schemas，供 LSP/键位编辑器）与 `eval_utils`（评测断言工具，只被 dev/optional 引用）都**不是 AI 专用**，前者是全仓基础设施，后者是测试专用 crate —— CSV 给 eval_utils 计了 2 个正式消费者，属误判。
8. 编辑预测分工：`edit_prediction` 是核心（FIM/raw completion/Sweep/udiff + `EditPredictionStore`，provider 仅 `{Ollama, OpenAiCompatibleApi, None}`），`edit_prediction_context` 组装 BM25/git-log/可编辑区域上下文，`zeta_prompt` 是 InN=0 的提示词叶子（被预测/上下文/指标共用，仍必需），`edit_prediction_types` 只放共享枚举与 delegate trait，`edit_prediction_ui` 出状态栏按钮与 provider 选择，`edit_prediction_metrics` 出指标并附带独立 CLI 评测二进制。
9. 已删云 provider 的痕迹：`crates/edit_prediction/src/zeta.rs` 只剩 104 行本地 diff→edits；crate 内无任何 zed.dev/cloud URL；但 `EditPredictionStore::new` 仍保留未使用的 `_client`/`_user_store` 参数（连带 client/db 依赖空壳），`language_model_core/src/provider.rs:3-25` 仍存 anthropic/baseten/google/x_ai/zed.dev 常量。
